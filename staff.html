🎓 Add a Course

The Courses page shows only what you add here. While this list is empty the page tells visitors that courses are on the way — so nothing is advertised before it exists. Fill in what you know, press Add, then press Publish Changes at the bottom.

Leave it unticked and the course stands on its own. Tick it and give the series a name, and every course with that same name is grouped together on the Courses page, in the order you set.

📹 Live Meetings & Class Recording

How it works: 1) Fill the meeting title below and press Create Meeting — the site makes a unique code.   2) Press Publish Changes at the bottom so the code becomes active.   3) Send the code to your students.   4) When it's time, press ▶ Start & Host to open the room yourself first — students then join with the code. You can record the class and turn on live translated captions inside the room.

Just want to record a lesson (no students)? Create a meeting named e.g. "Recording — Tafsir 1", publish, press ▶ Start & Host, use the ⏺ Record button in the room, then upload the saved file in the "Add a Paid Video" panel above.

💬 User Feedback

Every page of the site now carries a feedback form. When a visitor sends one, two things happen: it opens their mail app addressed to ammarwalidyounis@gmail.com — that is what delivers it to you — and a copy is kept on their own device.

Read this once. This website has no server. A page on GitHub Pages cannot receive and store a message from someone else's phone — there is nowhere for it to be written. So the list below shows only the messages sent from this device, which in practice means the ones you sent yourself while testing. The real inbox is your email. If you want every visitor's message collected in one place here instead, that needs either a small backend or a free form service connected to your address — say the word and it can be wired up.
